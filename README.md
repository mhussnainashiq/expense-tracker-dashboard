****Expense Tracker Dashboard****

A modern **Expense Tracker Dashboard** built with React and Node.js. This project helps users manage income, expenses, budgets, and financial categories through a clean and responsive dashboard.

 **Features**
* Financial dashboard
* Income & expense tracking
* Transaction management
* Budget management
* Category management
* Expense charts and analytics
* Profile & settings
* Responsive design
* JWT authentication
* MongoDB backend

**Tech Stack**

**Frontend**

* React
* Vite
* React Router
* Axios
* Recharts
* Lucide React

**Backend**

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT
* bcryptjs
  
**Run Locally**

**Frontend**
bash
cd client
npm install
npm run dev


**Frontend**


http://localhost:5173

**Backend**

   bash
cd server
npm install
npm run dev

**Backend**
http://localhost:5000
